# 使用说明

[English](user-guide.md) · [返回 README](../README.md)

## Prompt 与 Skill

在 **Prompts** 中保存名称和正文，之后可以搜索、编辑、复制或导出。分类和标签用于整理文本，标签本身不会执行命令。

内置 Skill 目标包括 **Codex、Claude Code、DeepSeek Harness、ZCode 和 Hermes**。在设置中核对检测到的位置，实际可用目标取决于本机 Agent 和目录。AgentHub 管理 Skill 副本，不负责安装这些 Agent；由宿主管理的内容保持只读。

添加 Skill 时，打开 **Skill → 添加 Skill**，输入 Git 仓库、HTTPS ZIP 地址或选择本机目录，再点击 **查找 Skill**。来源中需要包含 `SKILL.md`；同一来源有多个 Skill 时，可以选择加入哪些。**加入 Skill 库**之后，再单独选择 Agent 或项目，核对目标位置并确认安装。

来源检查会显示当前阶段和已用时间。可以点击 **取消**，或关闭添加弹窗、按 Esc 来停止检查。取消后等待临时文件清理完成再重试，同一数据目录不会同时运行两次检查。失败时先显示简短说明，展开错误详情可查看诊断信息。保存所选 Skill 是另一步操作，保存期间弹窗仍受保护，完成后才能关闭。

点击 Skill 名称可以查看 Skill 库中这份副本的文件，左侧文件列表与右侧正文分别滚动；聚焦相应区域后可使用 Page Up / Page Down。有 Git 网页来源时，**打开来源仓库 ↗** 会打开仓库主页。本机、ZIP 或未知来源继续使用内部查看器，不显示仓库链接。项目仓库书签也通过明确的外链入口打开。

更新前先检查变化并核对影响位置。Agent 图标保留品牌配色，勾选标记和绿色边框表示已安装；不可用的操作会变淡。Prompt 和 Skill 记录保存在本机，来源也可以来自网络。

## 核对下载文件

在 PowerShell 中运行 `Get-FileHash .\文件名 -Algorithm SHA256`，与同一次发布的 `SHA256SUMS.txt` 对照。`build-manifest.json` 记录版本、源码 commit、CI 运行、文件大小和签名状态，可结合官方发布页及其 CI 记录核对文件来源。清单中的自述信息不能单独证明发布者身份，也不能替代 Windows 发布者签名；数字签名也不保证立刻获得 SmartScreen 信誉。

## 运行要求

目前面向 Windows x64；各次发布的验收附件记录实际测试过的 Windows 版本、场景和文件哈希。

缺少 WebView2 时，安装程序会从 Microsoft 下载。离线、下载失败或取消后，可以恢复网络再试，或先从 [Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/#download-section) 安装 Evergreen Runtime。当前不提供完整的离线运行时安装包；便携版同样需要 WebView2。

Git 项目检查需要先由你确认信任。Git 可能调用本机配置中的 SSH、凭据助手或其他程序；撤销信任会阻止后续检查，修改项目路径需要重新确认。AgentHub 获取并比较上游变化，不会自动合并。来源与文件操作保护不能保证 Skill 被 Agent 执行时的安全性，使用前仍需查看内容。

## 数据、搬迁与恢复

重新安装会记住之前选择的安装目录，数据库位于 `data/agenthub.sqlite3`。普通卸载保留数据，主动勾选删除应用数据才会移除。备份前完全退出程序，再复制整个 `data` 文件夹；Prompt 也可以单独导出。

搬迁便携版目录时，AgentHub 只更新自身 Skill 库和备份的引用。外部项目、Agent 目录和本机来源仍保留原路径，需要重新检查更新。搬迁前先在原位置完成未结束的文件操作；如果已经搬走且出现恢复提示，应按界面说明移回原位置恢复。

Skill 恢复失败时，仍可使用和导出 Prompt，并查看备份与设置。界面保留诊断、受影响路径和重试入口。恢复成功前，Skill 写入及可能改变恢复依据的操作会暂停；不要删除恢复记录来强行继续写入。

多个 Agent 共用目录时，界面会显示关联影响，并且只处理一次该目录。网络操作遵循本机代理与工具配置；本地保存不代表应用从不联网。
