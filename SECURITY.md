# Reporting security issues

Please report security issues privately to **admin@hifermin.com**. Do not post details of unfixed vulnerabilities, tokens, private keys, private prompts, or personal databases in public issues.

Include the AgentHub version, Windows version, installation method, minimal reproduction steps, and expected and actual results. Share only the log excerpts needed to investigate, with personal information removed.

If the issue could expose private content, unexpectedly overwrite files, or make data unrecoverable, describe the affected scope in your email. Please keep vulnerability details in email until a fix is available.
